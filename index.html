6. Enterprise User Stories
ID User Role User Story Requirement Business Value / Acceptance Criteria
US-01 Guest Take an interactive olfactory profiling quiz Matches personal scent preferences to recommended fragrance families (Woody, Floral, Citrus, Oriental).
US-02 Customer Mix top, heart, and base notes in a custom creation studio Calculates formula ratios, displays real-time price updates, and renders bespoke bottle previews.
US-03 Customer Create an account using email and password via Supabase Auth Securely registers profile in Supabase PostgreSQL and issues JWT session tokens for persistent login.
US-04 Customer Log in securely to view personal dashboard Grants access to order history, saved perfume formulas, and current loyalty point balance.
US-05 Customer Add standard products and custom fragrance blends to shopping cart Persists cart state in browser local storage and syncs items smoothly into checkout.
US-06 Customer Complete checkout using PayFast payment gateway Supports Credit Card, Instant EFT, and Zapper payments with automated ITN payment callback verification.
US-07 Customer Track custom perfume blending status in real time Displays live status updates ("Pending" > "Blending" > "Dispatched") via Supabase Realtime subscriptions.
US-08 Customer Receive transactional status notifications via WhatsApp Automated WhatsApp Business API triggers message alerts upon dispatch and delivery.
US-09 Member Earn loyalty points on every completed transaction Automatically updates loyalty tier (Bronze, Silver, Gold, Velvet Elite) based on cumulative spend.
US-10 Member Save custom fragrance formulas under personalized names Stores note compositions in PostgreSQL JSONB column for seamless one-click re-ordering.
US-11 Admin Access real-time order fulfillment management dashboard Allows laboratory staff to view pending custom formula mix sheets and update dispatch status.
US-12 Admin Manage product catalog, fragrance notes stock, and prices Updates PostgreSQL products and notes tables instantly through admin RLS privileges.
US-13 Marketer Track visitor conversion funnels via Google Analytics 4 Captures custom events for quiz completions, studio creations, cart additions, and sales conversions.
US-14 Customer Save preferred delivery addresses in profile settings Stores structured JSON address data to accelerate future checkout sessions.
US-15 Admin Manually adjust customer loyalty points or apply VIP perks Enables customer support representatives to resolve inquiries or issue discretionary rewards.
