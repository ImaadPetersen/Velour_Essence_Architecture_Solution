1. Domain & Digital Platform Classification

Industry Domain

Luxury E-Commerce & Personalised Fragrance (Direct-to-Consumer): Merges haute parfumerie with digital customization, enabling customers to formulate, preview, and purchase bespoke scents online.

Digital Platform Architecture

Serverless Single-Page Web Application (SPA): High-speed Vanilla JS web client hosted on global Edge CDNs, interacting via REST APIs and WebSockets with Supabase cloud infrastructure.

Primary Stakeholders

VIP Customers & Laboratory Operations: Serves retail perfume enthusiasts creating signature blends alongside laboratory technicians managing order queues and bespoke formulas.

2. Functional Capabilities & Features

Customer Features (User Experience)

  • Olfactory Persona Quiz: Interactive quiz matching user preferences to scent families.
  • Interactive Scent Studio: Real-time blending interface for adjusting Top, Heart, and Base notes.
  • Bottle Customization & Engraving: Live SVG rendering of engraved names and bottle sizes.
  • Recipe Vault: Saved custom fragrance compositions with one-click re-ordering.
  • Seamless PayFast Checkout: PCI-compliant payments via Credit Card, Instant EFT, and Zapper.
  • Real-Time Tracking Dashboard: Live WebSocket tracking of custom blending progress.
  • Velvet Elite Loyalty Rewards: Automatic tier progression and points management.

Admin Features (Laboratory & Stock Operations)

  • Live Laboratory Mix Sheet Queue: Display of exact note volume ratios for custom order blending.
  • Fragrance Notes Stock Management: Real-time raw inventory tracking for individual scent notes.
  • One-Click Fulfillment Status Updates: Changes order state (Pending → Blending → Dispatched).
  • Automated WhatsApp Notifications: Automated messaging triggering customer dispatch updates.
  • VIP Customer & Points Management: Administrative overrides for points, discounts, and rewards.
  • Funnel Analytics Integration: Conversion tracking via Google Analytics 4 (GA4).

User Flow Step-by-Step Explanation:

1. Discovery & Profiling: Visitors begin either with an olfactory quiz or directly inside the creation studio.
2. Customization: Customers manipulate note balances, apply bottle engravings, and save their formulation.
3. Checkout & Fulfillment: Authentication ensures formulas are saved to the user's account before payment via PayFast. Successful authorization triggers automated laboratory queuing, WhatsApp notification, and loyalty point rewards.
