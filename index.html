Custom Luxury Perfumery Platform — Model Architecture, C4 Diagrams & Operational Specifications

1. Domain & Digital Platform Specifications

Industry Domain

Luxury E-Commerce & Personalised Fragrance (Direct-to-Consumer): Operates at the intersection of haute parfumerie and bespoke digital customization, allowing consumers to digitally formulate, preview, and purchase custom luxury fragrances online.

Digital Platform Classification

Serverless Single-Page Web Application (SPA): Built using a zero-framework Vanilla JavaScript core decoupled from backend services, hosted on Edge CDNs, and connected via APIs to backend-as-a-service infrastructure.

Target Audience & Reach

VIP Consumer & Retail Direct: High-value direct consumers seeking signature scents, social media inbound shoppers (Instagram/TikTok), and enterprise laboratory staff managing fulfillment.

2. Customer & Administrative Feature Matrices

User-Facing Features (Customer Experience)

  • Olfactory Profiling Quiz: Interactive preference quiz matching users to fragrance families (Woody, Floral, Citrus, Oriental).
  • Fragrance Creation Studio: Real-time blending interface for adjusting Top, Heart, and Base note volume ratios.
  • Bespoke Bottle Customization: Real-time rendering of custom bottle engravings and size selections.
  • Persistent Cart & VIP Checkout: LocalStorage cart state integrated with PayFast gateway (Credit Cards, Instant EFT, Zapper).
  • Personal Recipe Vault: Ability to name and save custom fragrance compositions for quick one-click re-ordering.
  • Real-Time Order Tracking: WebSocket-powered status updates (Pending → Blending → Dispatched).
  • Velvet Elite Loyalty: Automated tier progression (Bronze → Velvet Elite) and VIP perk redemption.

Administrative Features (Laboratory & Management)

  • Real-Time Mix Sheet Dashboard: Live laboratory queue displaying exact note ratios for bespoke fragrance blending.
  • Inventory & Stock Sync: Stock tracking for individual fragrance notes, raw materials, and custom bottle stock.
  • Order Dispatch Management: One-click fulfillment status updates triggering automated customer notifications.
  • Transactional WhatsApp Notifications: Integrated API triggers dispatching WhatsApp alerts upon order fulfillment.
  • Customer & VIP Loyalty Management: Discretionary loyalty points adjustments and VIP reward overrides.
  • Analytics & Conversion Tracking: GA4 conversion funnel analysis tracking quiz drop-offs and sales conversions.
